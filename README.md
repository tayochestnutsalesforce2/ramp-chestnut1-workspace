# RAMP project: Chestnut Ramp 1 (synthetic POC)

This branch is a RAMP-managed workspace for customer `chestnut-ramp1-poc`. Open it from RAMP's Project panel;
do not edit it by hand (every file is hashed in `ramp-manifest.json` and a hand edit makes the project unopenable).

**Synthetic data only.** This repository must never hold real customer data.

| Path | What it is |
|---|---|
| `ramp-manifest.json` | every workspace file, its hash and retention class, the revision it is based on |
| `workspace/` | the customer workspace, an exact mirror of `customers/<key>/` |
| `ramp/checkins/<id>.json` | one record per check-in, committed with it (self-attested consultant name) |
| `ramp/retention-policy.json` | which workspace files travel and which stay on the consultant's machine |
| `.gitattributes` | keeps every file byte-identical on every platform |

Retention policy v3. Generated by RAMP; regenerated only when its content changes.
